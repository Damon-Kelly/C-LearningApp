@q What is the default access level of members declared in a class?
@opt public
@opt private
@opt protected
@opt There is no default
@correct 2
@why class members are private by default. struct members are public by default.

@q What does this program print?
@code cpp
class Acc { int bal = 0;
public:
    void dep(int a) { if (a > 0) bal += a; }
    int get() const { return bal; } };
Acc x;
x.dep(10); x.dep(-4); x.dep(5);
cout << x.get() << endl;
@end
@opt 11
@opt 15
@opt 10
@opt 0
@correct 2
@why The negative deposit is rejected, so 10 + 5 = 15.

@q What does this program print?
@code cpp
struct T { char c;
    T(char x) : c(x) { cout << c; }
    ~T() { cout << c; } };
int main() {
    T a('X');
    { T b('Y'); }
}
@end
@opt XYYX
@opt XYXY
@opt XY
@opt XXYY
@correct 1
@why X is made, Y is made and destroyed at its closing brace, then X is destroyed at the end of main.

@q A class has only the constructor Box(double l, double w). What happens with Box b; ?
@opt b gets zero sizes
@opt Compile error: there is no default constructor
@opt The compiler adds one automatically
@opt b is a null pointer
@correct 2
@why Once any constructor is written, the compiler no longer supplies a default one.

@q What does this program print?
@code cpp
class Clock { public: int h, m;
  Clock(int a = 12, int b = 0) : h(a), m(b) {} };
Clock c1, c2(7);
cout << c1.h << ":" << c1.m << " ";
cout << c2.h << ":" << c2.m << endl;
@end
@opt 12:0 7:0
@opt 0:0 7:0
@opt 12:0 7:12
@opt 12:0 12:7
@correct 1
@why c1 uses both defaults. c2 gives h = 7 and uses the default m = 0.

@q Inside a member function, what is this?
@opt A copy of the object
@opt A pointer to the object the function was called on
@opt The name of the class
@opt The first data member
@correct 2
@why this holds the address of the calling object, and *this is the object itself.

@q What does this program print?
@code cpp
class C { int n = 1; public:
    C& dbl() { n *= 2; return *this; }
    int get() const { return n; } };
C c;
c.dbl().dbl().dbl();
cout << c.get() << endl;
@end
@opt 2
@opt 6
@opt 8
@opt 4
@correct 3
@why dbl returns a reference to c, so all three calls double the same object: 2, 4, 8.

@q How does the compiler tell postfix operator++ from prefix operator++?
@opt Postfix takes a dummy int parameter
@opt Postfix returns void
@opt Prefix takes a dummy int parameter
@opt They must have different names
@correct 1
@why operator++(int) is postfix. The int is only there to make the parameter lists different.

@q What does this program print?
@code cpp
struct N { int v; N(int x) : v(x) {}
    N operator++(int) {
        N s = *this; v++; return s; } };
N a(4);
N b = a++;
cout << a.v << " " << b.v << endl;
@end
@opt 5 5
@opt 5 4
@opt 4 5
@opt 4 4
@correct 2
@why Postfix ++ returns the saved old value (4) and increments a to 5.

@q Why is operator<< for a class normally a non-member friend?
@opt Its left operand is the stream, and it needs the private members
@opt Members cannot use cout
@opt friend functions run faster
@opt It must return void
@correct 1
@why A member operator would need the class on the left. friend grants access to private data.

@q What does this program print?
@code cpp
struct Q { int* v;
    Q(int x) : v(new int(x)) {} };
Q a(3);
Q b = a;
*b.v = 8;
cout << *a.v << endl;
@end
@opt 3
@opt 8
@opt 0
@opt 11
@correct 2
@why Q has no copy constructor, so b is a shallow copy: both pointers share one int.

@q Why does LinkedList::operator= start with if (this != &other)?
@opt To make the copy faster
@opt So that list = list does not clear itself before copying
@opt To call the destructor
@opt It is required to return *this
@correct 2
@why Self-assignment would free the nodes and then copy from an empty list.

@q What does this program print?
@code cpp
struct D { int data; D *prev, *next; };
D a = {1}, b = {2}, c = {3};
a.next = &b; b.next = &c;
b.prev = &a; c.prev = &b;
D* p = &c;
p = p->prev->prev;
cout << p->data << p->next->data << endl;
@end
@opt 12
@opt 32
@opt 21
@opt 23
@correct 1
@why Two steps back from c reaches a. a's data is 1 and its next is b, holding 2.
