@q What does this program print?
@code c
int x = 10;
if (x > 5) { printf("A"); }
else if (x > 8) { printf("B"); }
else { printf("C"); }
printf("\n");
@end
@opt A
@opt AB
@opt B
@opt C
@correct 1
@why The first true condition runs and the rest of the chain is skipped, so only A is printed.

@q What does this program print?
@code c
int a = 0, b = 1;
if (a)
    if (b) printf("X\n");
    else printf("Y\n");
printf("Z\n");
@end
@opt X
@opt Y
@opt Z
@opt Y and Z
@correct 3
@why a is false, so the inner if is never reached. The else belongs to the inner if, so Y is not printed either. Only Z prints.

@q What does this program print?
@code c
int n = 2, r = 0;
switch (n) {
    case 1: r += 1;
    case 2: r += 2;
    case 3: r += 3; break;
    default: r += 9;
}
printf("%d\n", r);
@end
@opt 2
@opt 5
@opt 6
@opt 14
@correct 2
@why It jumps to case 2 (adds 2), falls into case 3 (adds 3), and break stops there.

@q Which of these cannot be used as the value of a switch in C?
@opt int
@opt char
@opt double
@opt an enum
@correct 3
@why switch works on integer types only.

@q What does this program print?
@code c
int n = 10;
do { n++; } while (n < 5);
printf("%d\n", n);
@end
@opt 10
@opt 11
@opt 5
@opt 4
@correct 2
@why The body runs once before the condition is checked, so n becomes 11.

@q What does this program print?
@code c
int c = 0;
for (int i = 1; i <= 5; i++) {
    if (i % 2 == 0) { continue; }
    c += i;
}
printf("%d\n", c);
@end
@opt 6
@opt 9
@opt 15
@opt 5
@correct 2
@why continue skips the even numbers, so only 1, 3 and 5 are added.

@q What does this program print?
@code c
int c = 0;
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) { break; }
        c++;
    }
}
printf("%d\n", c);
@end
@opt 0
@opt 3
@opt 6
@opt 9
@correct 2
@why break leaves only the inner loop. For each of the 3 outer passes, c++ runs once (j = 0) before j = 1 stops it.

@q What does this program print?
@code c
int c = 0;
for (int i = 0; i < 4; i++)
    for (int j = 0; j < 2; j++)
        c++;
printf("%d\n", c);
@end
@opt 6
@opt 8
@opt 4
@opt 2
@correct 2
@why The inner loop runs 2 times for each of the 4 outer passes: 4 * 2 = 8.

@q What does this program print?
@code c
int a = 4;
printf("%d\n", a % 2 == 0 ? a / 2 : a * 3 + 1);
@end
@opt 2
@opt 13
@opt 4
@opt 1
@correct 1
@why a is even, so the value before the colon is used: 4 / 2 is 2.

@q What is wrong with the statement if (x = 5)?
@opt Nothing, it tests whether x is 5
@opt It assigns 5 to x, so the condition is always true
@opt It does not compile in C
@opt It only works for chars
@correct 2
@why A single = assigns. Comparison needs ==.

@q A while loop tests i <= 3 but the body never changes i. What happens?
@opt It runs 3 times
@opt It does not run
@opt It runs forever
@opt The compiler reports an error
@correct 3
@why The condition never becomes false, so the loop never ends.

@q What does this program print?
@code c
int n = 702, s = 0;
while (n > 0) { s += n % 10; n /= 10; }
printf("%d\n", s);
@end
@opt 9
@opt 702
@opt 7
@opt 11
@correct 1
@why The digits are 2, 0 and 7, and 2 + 0 + 7 is 9.
