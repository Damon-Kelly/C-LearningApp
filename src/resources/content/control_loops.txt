#---------------------------------------------------------------------------
@page explain while and do-while
@text
A while loop checks its condition before every pass and repeats the body while it is true. Something inside the loop must eventually make the condition false, or the loop never ends.
@end
@code c
int i = 1;
while (i <= 3) {
    printf("%d\n", i);
    i++;
}
@output
1
2
3
@end
@text
A do-while loop checks the condition after the body, so the body always runs at least once. Note the semicolon after the closing while.
@end
@code c
int n = 10;
do {
    printf("%d\n", n);
    n++;
} while (n < 5);
@output
10
@end
@text
The condition n < 5 was already false, but the body ran once first. That makes do-while ideal for "ask, then check" situations such as input validation.
@end

#---------------------------------------------------------------------------
@page explain The for loop
@text
A for loop packs the three parts of a counting loop into one line: a start, a condition, and an update. It runs the start once, then repeats condition, body, update.
@end
@code c
for (int i = 0; i < 4; i++) {
    printf("%d\n", i * i);
}
@output
0
1
4
9
@end
@text
for (int i = 0; i < 4; i++) is the standard way to repeat something 4 times: i takes the values 0, 1, 2, 3. Writing <= 4 instead would run 5 times. This off-by-one mistake is the most common loop bug.
@end
@code c
int sum = 0;
for (int i = 1; i <= 5; i++) {
    sum += i;
}
printf("%d\n", sum);
@output
15
@end
@text
Use for when you know how many times to loop, and while when you loop until something happens.
@end

#---------------------------------------------------------------------------
@page explain break and continue
@text
break leaves the loop immediately. continue skips the rest of the current pass and goes on to the next one, running the update and the condition as usual.
@end
@code c
for (int i = 1; i <= 6; i++) {
    if (i == 2) { continue; }
    if (i == 5) { break; }
    printf("%d\n", i);
}
@output
1
3
4
@end
@text
2 was skipped by continue and the loop ended at 5 because of break, so 5 and 6 never printed. A loop whose condition never becomes false runs forever; while (1) { ... } is a deliberate infinite loop that relies on break to end.
@end

@text
What does this program print?
@end
@code c
int n = 0;
for (int i = 0; i < 10; i += 3) {
    n += i;
}
printf("%d\n", n);
@output
18
@end
@option 9
@option 12
@option 27
@option 18
@answer 4
@why i takes the values 0, 3, 6 and 9, then 12 stops the loop. Their sum is 18.

@why continue jumps to the next pass, running the update and condition.
