@topic Common array patterns
@summary Finding the maximum, searching and reversing

#---------------------------------------------------------------------------
@page explain Maximum and search
@text
Most array problems are the same loop with a different job inside. To find the largest value, start with the first element and replace it whenever you meet a bigger one. Start from a[0], not from 0, because every value might be negative.
@end
@code c
int maxOf(int a[], int n) {
    int best = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > best) {
            best = a[i];
        }
    }
    return best;
}

int main(void) {
    int a[5] = {3, 9, 2, 7, 4};
    printf("%d\n", maxOf(a, 5));
    return 0;
}
@output
9
@end
@text
To search, return the index as soon as you find the target, and return -1 after the loop if you never do. -1 works because it can never be a real index.
@end
@code c
int indexOf(int a[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (a[i] == target) {
            return i;
        }
    }
    return -1;
}

int main(void) {
    int a[4] = {5, 8, 1, 8};
    printf("%d %d\n", indexOf(a, 4, 8), indexOf(a, 4, 3));
    return 0;
}
@output
1 -1
@end
@text
Notice that both functions take the length n as a separate parameter. An array parameter is only an address, so the function cannot work out the length by itself. For the same reason, changes a function makes to a[i] are visible in the caller's array.
@end

@page explain Reversing in place
@text
To reverse an array, swap the first element with the last, the second with the second-to-last, and so on. You only need to go halfway: each swap fixes two elements, and going further would swap them back.
@end
@code c
int a[5] = {1, 2, 3, 4, 5};
int n = 5;
for (int i = 0; i < n / 2; i++) {
    int t = a[i];
    a[i] = a[n - 1 - i];
    a[n - 1 - i] = t;
}
for (int i = 0; i < n; i++) {
    printf("%d%s", a[i], i < n - 1 ? " " : "\n");
}
@output
5 4 3 2 1
@end
@text
The element opposite a[i] is a[n - 1 - i]. With 5 elements, n / 2 is 2, so the middle element stays where it is, which is exactly right.
@end

@page trace Reversing four numbers
@code c
int a[4] = {1, 2, 3, 4};
int t = a[0];
a[0] = a[3];
a[3] = t;
t = a[1];
a[1] = a[2];
a[2] = t;
@end
@step 1
@cell a[0] int 1 1000
@cell a[1] int 2 1004
@cell a[2] int 3 1008
@cell a[3] int 4 1012
@note The starting array.
@step 2
@cell a[0] int 1 1000
@cell a[1] int 2 1004
@cell a[2] int 3 1008
@cell a[3] int 4 1012
@cell t int 1 1016
@note t saves a[0] so it is not lost when we overwrite it.
@step 3
@cell a[0] int 4 1000
@cell a[1] int 2 1004
@cell a[2] int 3 1008
@cell a[3] int 4 1012
@cell t int 1 1016
@note The last value is copied into the first slot.
@step 4
@cell a[0] int 4 1000
@cell a[1] int 2 1004
@cell a[2] int 3 1008
@cell a[3] int 1 1012
@cell t int 1 1016
@note The saved value goes into the last slot. First and last are swapped.
@step 5
@cell a[0] int 4 1000
@cell a[1] int 2 1004
@cell a[2] int 3 1008
@cell a[3] int 1 1012
@cell t int 2 1016
@note The same trick for the middle pair: save a[1].
@step 6
@cell a[0] int 4 1000
@cell a[1] int 3 1004
@cell a[2] int 3 1008
@cell a[3] int 1 1012
@cell t int 2 1016
@note a[2] is copied into a[1].
@step 7
@cell a[0] int 4 1000
@cell a[1] int 3 1004
@cell a[2] int 2 1008
@cell a[3] int 1 1012
@cell t int 2 1016
@note The saved value goes into a[2]. The array now reads 4 3 2 1.

@page predict Predict the output
@text
What does this program print?
@end
@code c
int a[5] = {4, 8, 1, 9, 3};
int best = 0;
for (int i = 1; i < 5; i++) {
    if (a[i] > a[best]) best = i;
}
printf("%d %d\n", best, a[best]);
@output
3 9
@end
@option 3 9
@option 9 3
@option 4 9
@option 3 3
@answer 1
@why best stores an index, not a value. The largest value is 9, which sits at index 3, so it prints the index first and then a[3].

@page quiz Check your understanding
@q Why does a maximum search start with best = a[0] instead of best = 0?
@opt It is faster
@opt Every value might be negative, and 0 would wrongly win
@opt Arrays cannot hold 0
@opt The loop would not run otherwise
@correct 2
@why Starting from a real element is always safe. Starting from 0 gives the wrong answer for an all-negative array.

@q What should a search function return when the target is not found?
@opt 0
@opt The array length
@opt -1
@opt Nothing, it cannot fail
@correct 3
@why 0 is a valid index, so a value outside the valid range such as -1 is used to mean not found.

@q Why does an in-place reverse only loop up to n / 2?
@opt Each swap fixes two elements, and going further would undo the work
@opt The array only has n / 2 elements
@opt Swapping is slow
@opt The last half is already sorted
@correct 1
@why Swapping a[i] with its opposite handles both ends at once. Doing all n would swap every pair twice.

@q Why does void show(int a[], int n) take n as well as the array?
@opt To make the function faster
@opt The function only receives an address and cannot know the length
@opt Arrays start at n
@opt It does not need it
@correct 2
@why The array parameter is just a pointer to the first element, with no length attached.

@q A function does a[0] = 99 on its int a[] parameter. What happens to the caller's array?
@opt Nothing, it was a copy
@opt The caller's first element becomes 99
@opt The program does not compile
@opt The whole array is set to 99
@correct 2
@why The function was given the address of the caller's array, so it changes the original.
