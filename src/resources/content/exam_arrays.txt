@q What does this program print?
@code c
int a[5] = {2, 4, 6, 8, 10};
printf("%d\n", a[1] + a[3]);
@end
@opt 12
@opt 10
@opt 14
@opt 6
@correct 1
@why a[1] is 4 and a[3] is 8. Indexes start at 0.

@q What is the last valid index of int data[8]?
@opt 8
@opt 7
@opt 9
@opt 0
@correct 2
@why Indexes run from 0 to size - 1.

@q What does this program print?
@code c
int g[2][3] = {{1, 2, 3}, {4, 5, 6}};
printf("%d\n", g[1][1] + g[0][2]);
@end
@opt 8
@opt 7
@opt 6
@opt 9
@correct 1
@why g[1][1] is the middle of the second row (5) and g[0][2] is the end of the first row (3).

@q Why must a function that receives a 2D array be told the number of columns?
@opt To know how many rows there are
@opt To find where each row starts in memory
@opt Because the array is copied
@opt It does not need to be
@correct 2
@why The array is stored row after row, so the column count is needed to jump from one row to the next.

@q What does this program print?
@code c
char s[] = "abc";
s[1] = 'X';
printf("%s\n", s);
@end
@opt aXc
@opt abc
@opt Xbc
@opt abX
@correct 1
@why s[1] is the second character, so 'b' is replaced by 'X'.

@q What is the longest string that char name[6]; can hold?
@opt 6 letters
@opt 5 letters
@opt 7 letters
@opt 4 letters
@correct 2
@why One of the 6 slots is needed for the terminating '\0'.

@q What does this program print?
@code c
char s[] = "hello";
printf("%zu %zu\n", strlen(s), sizeof(s));
@end
@opt 5 6
@opt 5 5
@opt 6 6
@opt 6 5
@correct 1
@why strlen counts the 5 letters. sizeof counts the whole array, which includes the terminator.

@q What does strcmp return when the two strings are equal?
@opt 1
@opt -1
@opt 0
@opt The length
@correct 3
@why strcmp returns 0 for equal strings, so equality is tested with == 0.

@q What does this program print?
@code c
int a[4] = {3, 1, 4, 1};
int count = 0;
for (int i = 0; i < 4; i++) {
    if (a[i] == 1) count++;
}
printf("%d\n", count);
@end
@opt 2
@opt 1
@opt 4
@opt 0
@correct 1
@why The loop counts how many elements equal 1: a[1] and a[3].

@q What does 'd' - 'a' evaluate to?
@opt 3
@opt 4
@opt 100
@opt 'd'
@correct 1
@why Letter codes are consecutive, so the difference is how far apart the letters are.

@q What does this program print?
@code c
int a[3] = {5, 6, 7};
int *p = a;
printf("%d\n", *(p + 1) + p[2]);
@end
@opt 13
@opt 12
@opt 18
@opt 11
@correct 1
@why *(p + 1) is a[1] (6) and p[2] is a[2] (7).

@q Which declaration creates a table with 4 rows and 5 columns?
@opt int t[5][4];
@opt int t[4][5];
@opt int t[4, 5];
@opt int t[20];
@correct 2
@why The first size is rows, the second is columns.
