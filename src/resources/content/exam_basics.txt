@q Which type is the best fit for storing the value 3.7?
@opt int
@opt double
@opt char
@opt bool
@correct 2
@why int would cut off the decimals. double holds numbers with a decimal part.

@q What does this program print?
@code c
int a = 17, b = 5;
printf("%d\n", a / b + a % b);
@end
@opt 3
@opt 3.4
@opt 5
@opt 2
@correct 3
@why 17 / 5 is 3 (integer division) and 17 % 5 is 2, so the sum is 5.

@q What does this program print?
@code c
int i = 4;
int a = i++;
int b = ++i;
printf("%d %d %d\n", a, b, i);
@end
@opt 4 6 6
@opt 5 6 6
@opt 4 5 6
@opt 4 6 5
@correct 1
@why a gets 4 and then i becomes 5. ++i makes i 6 first, so b is 6 and i is 6.

@q What does this program print?
@code c
printf("%.1f\n", (double)(7 / 2));
@end
@opt 3.5
@opt 3.0
@opt 3
@opt 4.0
@correct 2
@why The integer division 7 / 2 happens first and gives 3. The cast then turns 3 into 3.0.

@q Which header gives you bool in C?
@opt stdio.h
@opt stdbool.h
@opt bool.h
@opt stdlib.h
@correct 2
@why stdbool.h defines bool, true and false in C99. C++ has them built in.

@q Which call correctly reads an int into n?
@opt scanf("%d", n);
@opt scanf("%f", &n);
@opt scanf("d", &n);
@opt scanf("%d", &n);
@correct 4
@why %d matches an int and &n passes the address so scanf can change n.

@q What does this C++ program print?
@code cpp
int a = 7;
cout << a / 2 << " " << a / 2.0 << endl;
@end
@opt 3 3.5
@opt 3.5 3.5
@opt 3 3
@opt 3.5 3
@correct 1
@why a / 2 is an integer division and gives 3. a / 2.0 involves a double and gives 3.5.

@q What does this program print?
@code c
printf("%.3f|%d%%\n", 2.0, 50);
@end
@opt 2.0|50%
@opt 2.000|50
@opt 2|50%
@opt 2.000|50%
@correct 4
@why %.3f shows three decimals and %% prints one percent sign.

@q What does this program print?
@code c
printf("%d\n", (5 > 3) + (2 > 4) + (1 == 1));
@end
@opt 0
@opt 1
@opt 2
@opt 3
@correct 3
@why The comparisons give 1, 0 and 1. In C, true is 1 and false is 0.

@q Which statement reads a whole line, including spaces, into the string line in C++?
@opt cin >> line;
@opt getline(cin, line);
@opt cin.read(line);
@opt readline(cin);
@correct 2
@why cin >> stops at whitespace. getline reads to the end of the line.

@q Why does (int)3.99 give 3?
@opt Casting to int cuts off the decimal part
@opt Casting rounds to the nearest integer
@opt Casting always rounds up
@opt It is a compile error
@correct 1
@why Converting a double to an int truncates toward zero.

@q What does this program print?
@code c
printf("%d\n", 2 + 3 * 4 % 5);
@end
@opt 14
@opt 4
@opt 0
@opt 20
@correct 2
@why * and % go left to right: 3 * 4 is 12, 12 % 5 is 2, and 2 + 2 is 4.
