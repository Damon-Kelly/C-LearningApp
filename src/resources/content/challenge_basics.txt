@challenge Celsius to Fahrenheit
@level 1
@text
Write a function toFahrenheit that takes a temperature in degrees Celsius (a double) and returns it in degrees Fahrenheit.

The formula is F = C x 9 / 5 + 32. Watch out: in C, 9 / 5 is an integer division.
@end
@starter
double toFahrenheit(double c) {
    // your code here
    return 0;
}
@end
@solution
double toFahrenheit(double c) {
    return c * 9.0 / 5.0 + 32.0;
}
@end
@hint Use 9.0 / 5.0 (or multiply first) so the division keeps its decimal part.
@test freezing point
printf("%.1f\n", toFahrenheit(0));
@expect
32.0
@end
@test boiling point
printf("%.1f\n", toFahrenheit(100));
@expect
212.0
@end
@test a fraction
printf("%.1f\n", toFahrenheit(37.5));
@expect
99.5
@end
@hidden below zero
printf("%.1f\n", toFahrenheit(-40));
@expect
-40.0
@end

@challenge Seconds to a clock time
@level 2
@text
Write a function printTime that takes a number of seconds and prints it as hours:minutes:seconds, followed by a new line.

Minutes and seconds always have two digits, so 3725 seconds prints 1:02:05. Use / and % to split the number.
@end
@starter
#include <stdio.h>

void printTime(int seconds) {
    // your code here
}
@end
@solution
#include <stdio.h>

void printTime(int seconds) {
    int h = seconds / 3600;
    int m = seconds % 3600 / 60;
    int s = seconds % 60;
    printf("%d:%02d:%02d\n", h, m, s);
}
@end
@hint seconds / 3600 gives the hours; seconds % 3600 is what is left over. %02d prints at least two digits.
@test an hour and a bit
printTime(3725);
@expect
1:02:05
@end
@test under a minute
printTime(59);
@expect
0:00:59
@end
@test exactly one day
printTime(86400);
@expect
24:00:00
@end
@hidden zero
printTime(0);
@expect
0:00:00
@end

@challenge Average of three
@level 1
@text
Write a function average3 that takes three ints and returns their average as a double.

average3(1, 2, 2) should be 1.666..., not 1. The ints must be converted before dividing.
@end
@starter
double average3(int a, int b, int c) {
    // your code here
    return 0;
}
@end
@solution
double average3(int a, int b, int c) {
    return (a + b + c) / 3.0;
}
@end
@hint Divide by 3.0 instead of 3, or cast the sum with (double).
@test whole result
printf("%.2f\n", average3(2, 4, 6));
@expect
4.00
@end
@test a fraction
printf("%.2f\n", average3(1, 2, 2));
@expect
1.67
@end
@test negatives
printf("%.2f\n", average3(-5, 0, 2));
@expect
-1.00
@end
@hidden halves
printf("%.2f\n", average3(1, 1, 2));
@expect
1.33
@end
