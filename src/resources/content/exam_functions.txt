@q What does this program print?
@code c
int f(int a, int b) { return 2 * a + b; }

int main(void) {
    printf("%d\n", f(3, 4));
}
@end
@opt 7
@opt 10
@opt 24
@opt 14
@correct 2
@why f(3, 4) returns 2 * 3 + 4 = 10.

@q Which return type do you give a function that returns nothing?
@opt null
@opt none
@opt void
@opt empty
@correct 3
@why void means the function gives back no value.

@q What does this program print?
@code c
int tick(void) { static int n = 0; return ++n; }

int main(void) {
    tick(); tick();
    printf("%d\n", tick());
}
@end
@opt 1
@opt 3
@opt 2
@opt 0
@correct 2
@why n is static, so it keeps its value between calls: 1, then 2, then 3 on the third call.

@q What is the purpose of a function prototype?
@opt It makes the function run faster
@opt It frees the function's variables
@opt It declares the name, parameters and return type before the definition appears
@opt It turns the function into a global variable
@correct 3
@why The compiler needs to know how a function looks before it sees a call to it.

@q What does this program print?
@code c
int f(int n) {
    if (n == 0) { return 1; }
    return 2 * f(n - 1);
}

int main(void) {
    printf("%d\n", f(4));
}
@end
@opt 8
@opt 16
@opt 32
@opt 4
@correct 2
@why f(4) doubles 1 four times: 2 * 2 * 2 * 2 * f(0) = 16.

@q What is the job of the base case in a recursive function?
@opt It makes the function faster
@opt It declares the function
@opt It counts how many calls were made
@opt It stops the recursion by answering directly
@correct 4
@why Without a base case the function keeps calling itself until the stack overflows.

@q What does this C++ program print?
@code cpp
void f(int &a, int b) { a = 5; b = 5; }

int main() {
    int x = 1, y = 3;
    f(x, y);
    cout << x << " " << y << endl;
}
@end
@opt 5 3
@opt 5 5
@opt 1 3
@opt 1 5
@correct 1
@why a is a reference to x, so x becomes 5. b is a copy of y, so y stays 3.

@q Which pair of declarations is a valid overload in C++?
@opt int f(int a);  and  double f(int a);
@opt void f(int a);  and  void f(double a);
@opt void f(int a);  and  void f(int b);
@opt int f(int a);  and  int f(int a);
@correct 2
@why Overloads must differ in their parameter types or count. A different return type or parameter name is not enough.

@q Which of these languages lets you write two functions with the same name and different parameters?
@opt Only C
@opt Both C and C++
@opt Only C++
@opt Neither
@correct 3
@why Overloading exists only in C++. In C every function name is unique.

@q What does this program print?
@code c
void f(int *p) { p = NULL; }

int main(void) {
    int a = 5;
    int *q = &a;
    f(q);
    printf("%d\n", q == NULL ? 0 : *q);
}
@end
@opt 5
@opt 0
@opt nothing is printed
@opt 6
@correct 1
@why The pointer itself is passed by value. Setting p to NULL changes only f's copy, so q still points at a.

@q What does this C++ program print?
@code cpp
int add(int a, int b = 10) { return a + b; }

int main() {
    cout << add(1) << endl;
}
@end
@opt 1
@opt 10
@opt 11
@opt compile error
@correct 3
@why The call leaves out b, so it takes its default value 10. The result is 1 + 10.

@q What happens to a normal local variable when its function returns?
@opt It is destroyed
@opt It keeps its value for the next call
@opt It is visible to every function
@opt It is set to 0 automatically
@correct 1
@why A local variable exists only while its function is running, unless it is declared static.
